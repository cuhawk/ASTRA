# Session 5: LLM proxy (Gemini free tier + Anthropic Pro cascade)

Branch: `feat/llm-proxy`
Goal: Backend-only LLM mediation layer. Core analysis pipeline never touches it — only NL→Cypher translation, chain triage, and embeddings. Two tiers with a hard global kill-switch.

## Decisions (locked 2026-05-22)

- **HTTP runtime:** raw `httpx` for both providers. No official SDK deps. Simpler retry + budget control.
- **Tier:** inferred from vault — if user has an Anthropic key stored, route Pro; else route Free. No `users.tier` column.
- **Gemini:** `gemini-2.5-flash` for completions (cheap, fast); `text-embedding-004` for embeddings. Single ASTRA-owned key from `ASTRA_GEMINI_API_KEY`.
- **Anthropic cascade:** Sonnet first; only escalate to Opus when explicit `advise(chain_id, prompt)` is called with `prefer_opus=True` OR the Sonnet response is `{"verdict": "uncertain"}`. No implicit fallback.
- **Killswitch:** Redis-backed daily spend ceiling `ASTRA_DAILY_SPEND_CAP_USD` (default $20 free + unlimited pro since pro pays). Hot path uses `INCRBYFLOAT` on `llm_spend:<provider>:<YYYY-MM-DD>`; key TTL 26h.
- **Logging:** every call appends a row to `audit_llm_calls` (new table). Append-only. Cost computed client-side from token counts × per-model rate.

## Schema delta

Append to `backend/db/schema.sql`:

```sql
CREATE TABLE IF NOT EXISTS audit_llm_calls (
    id                  INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id             INTEGER REFERENCES users(id) ON DELETE SET NULL,
    provider            TEXT    NOT NULL,   -- 'gemini' | 'anthropic'
    model               TEXT    NOT NULL,
    reason              TEXT    NOT NULL,   -- 'nl_to_cypher' | 'chain_triage' | 'embed'
    prompt_tokens       INTEGER NOT NULL DEFAULT 0,
    completion_tokens   INTEGER NOT NULL DEFAULT 0,
    cost_usd            REAL    NOT NULL DEFAULT 0.0,
    outcome             TEXT    NOT NULL,   -- 'ok' | 'rate_limited' | 'killswitch' | 'error'
    duration_ms         INTEGER NOT NULL DEFAULT 0,
    at                  INTEGER NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_audit_llm_calls_user_at ON audit_llm_calls(user_id, at);
CREATE INDEX IF NOT EXISTS idx_audit_llm_calls_at      ON audit_llm_calls(at);
```
